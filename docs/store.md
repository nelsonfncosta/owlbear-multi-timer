# Multi Timer

Multi Timer lets you attach shared countdown timers to character and prop items in Owlbear Rodeo.

![Multi Timer running in Owlbear Rodeo](https://nelsonfncosta.github.io/owlbear-multi-timer/image.png)

## Features

- Add, pause, resume, restart, and remove timers.
- Keep active timers ordered by remaining time.
- Notify the table when a timer completes.
- Timer creators and GMs can manage timers while everyone can view them.
- Optionally dim or turn off a linked Dynamic Fog light when a timer ends.
- Click a timer name to focus its item on the scene.

## Usage

Select a character or prop, open the context menu and configure a new timer. Open the Multi Timer action to monitor all configured timers in the scene.
